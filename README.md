# Grow Together — 與你一起成長

一款結合自我成長任務管理與奇幻精靈養成的單頁 Web App。

## 線上體驗

https://imyujui.github.io/grow-together/

## 功能

- 月光、星火、森語三種精靈及自訂名稱
- 任務新增、編輯、刪除、完成與篩選
- 10／20／30 EXP 與五階段進化
- 餵食、玩耍、休息、摸摸及表情動畫
- 六項成就、成長統計與連續天數
- LocalStorage 自動保存及旅程紀錄匯出
- 桌機與手機響應式版面

所有 HTML、CSS、JavaScript 均整合於單一 `index.html`，不需後端、帳號、資料庫或付費 API。
